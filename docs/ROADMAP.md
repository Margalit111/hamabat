# תוכנית המשך

## עיקרון
האתר הציבורי הוא קבצים סטטיים בלבד. אין בו קוד של מערכת הניהול, מסד נתונים או סודות.
מערכת הניהול נפרדת לגמרי, ומעדכנת את האתר רק דרך "פרסום": יצירת `site.json` והפעלת בנייה.

```
admin (React)  →  api (Node + PostgreSQL)  →  "פרסום": site.json + Deploy Hook  →  website (סטטי)
admin.example.co.il   api.example.co.il                                          www.example.co.il
```

## שלבים
1. **שלב 1 (בוצע):** אתר Next.js סטטי שקורא מ־`content/site.json`.
2. **שלב 2:** `api` + מסד נתונים לפי `types.ts`; endpoint שמייצא את התוכן בפורמט `site.json`.
   בנייה: ב־`getContent` (`website/src/lib/content.ts`) מחליפים קריאת קובץ ב־`fetch` ל־API בזמן הבנייה. שאר האתר לא משתנה.
3. **שלב 3:** `admin` (React) – CRUD לקורסים/מפגש/צוות/הגדרות, העלאת תמונות, טיוטה → פרסום.
4. **שלב 4:** הקשחה (ראו למטה), גיבויים, יומן פעולות.

## אבטחה (ממשק הניהול)
* תת־דומיין נפרד, `noindex`, ללא קישור מהאתר.
* Cloudflare Access / הגבלת IP לפני מסך ההתחברות.
* התחברות עם 2FA, הרשאות לפי תפקיד (נבדקות בשרת), Rate limiting.
* CORS מצומצם לדומיין הניהול בלבד; מסד הנתונים לא חשוף לאינטרנט.
* גיבויים אוטומטיים ויומן פעולות (מי שינה מה ומתי).

## שיפורי נתונים מומלצים לפני שלב 2
* להחליף את `meeting.date` (טקסט) בתאריך ISO אמיתי ולעצב אותו בעברית באתר.
* להוסיף לכל קורס `startDate` אמיתי (במקום `details.start` כטקסט), כדי שאפשר יהיה למיין ולהסתיר אוטומטית ולהוסיף `startDate` ל־Schema.org.
* להוסיף תמונת Open Graph כללית (1200×630) לדף הבית.

## אופטימיזציית ביצועים
* האתר טוען גופנים מ־Google Fonts: להחליף ב־`next/font` או באחסון עצמי (עדיף גם לפרטיות).
* ה־CSS הועתק כמעט כמות שהוא, כולל ווריאנטים שלא בשימוש (flower / frame / thread). אפשר לנקות.
* להריץ Lighthouse על הנייד ולבדוק את משקל התמונות (הפוסטרים ~200KB; אפשר WebP).
